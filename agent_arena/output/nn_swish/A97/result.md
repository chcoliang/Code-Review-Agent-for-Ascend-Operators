# Swish 算子定义代码审查报告

**文件**: `swish_def.cpp`  
**审查日期**: 2026-08-05

---

### Bug #1: 无效的 SoC 版本名称 "mc62cm12a"

| 项目 | 内容 |
|------|------|
| **位置** | 第 42 行: `this->AICore().AddConfig("mc62cm12a", aicoreConfig);` |
| **类型** | 编译选项/平台配置错误 |
| **严重程度** | 严重 (Critical) |
| **描述** | "mc62cm12a" 不是任何已知 Ascend NPU SoC 的合法版本标识符。Ascend 平台合法的 SoC 版本字符串包括 "ascend310"、"ascend310p"、"ascend910"、"ascend910b"、"ascend910_93"、"ascend910_95" 等。该字符串不符合任何已知命名规范，会导致算子无法在目标平台上注册和部署。 |
| **触发条件** | 算子编译部署时，框架尝试根据 SoC 版本匹配配置，"mc62cm12a" 无法匹配任何实际硬件平台，该配置项将被忽略或导致注册失败。 |
| **测试方案** | 1. 在实际 Ascend 硬件环境中编译算子包，检查是否有 SoC 版本不识别的告警或错误。<br>2. 使用 `atc` 工具指定不同 SoC 版本进行模型转换，确认算子可正常加载。<br>3. 将 "mc62cm12a" 替换为正确的目标平台标识符（如 "ascend910b"），验证算子注册成功。 |

### Bug #2: opFile.value 配置值 "swish_apt" 疑似错误

| 项目 | 内容 |
|------|------|
| **位置** | 第 40 行: `.ExtendCfgInfo("opFile.value", "swish_apt");` |
| **类型** | 编译选项/内核文件链接错误 |
| **严重程度** | 高 (High) |
| **描述** | `opFile.value` 用于指定算子内核实现文件名。此处设置为 "swish_apt"，但 Swish 算子的内核实现文件通常命名为 "swish"。若实际内核文件名为 `swish.cpp` 而非 `swish_apt.cpp`，编译阶段将找不到对应的内核实现文件，导致算子编译失败。"_apt" 后缀暗示可能误用了自动并行切分(APT)模板的文件名或存在拼写错误。 |
| **触发条件** | 算子编译时，构建系统根据 `opFile.value` 查找内核实现源文件。若工程中不存在名为 `swish_apt.cpp`/`swish_apt.py` 的内核文件，将触发文件找不到的编译错误。 |
| **测试方案** | 1. 检查工程目录中内核实现文件的实际文件名，确认是否存在 `swish_apt` 命名的文件。<br>2. 若内核文件为 `swish.cpp`，将此处修改为 `"swish"` 后重新编译，验证编译通过。<br>3. 端到端执行 Swish 算子，确认能正确调用到内核实现。 |
