# Code Review: aclnn_scaled_masked_softmax.cpp

## Bug 1: CheckNotNull 未检查输出张量 y 的空指针

- **位置**: 第 46-52 行
- **类型**: 空指针解引用风险
- **严重程度**: 高
- **描述**: `CheckNotNull` 函数接收参数 `y`，但函数体内只检查了 `x` 和 `mask` 是否为空，没有对 `y` 进行空指针检查。后续 `CheckDtypeValid` 和 `CheckTensorDim` 中会直接使用 `y`，若 `y` 为 `nullptr` 将导致空指针解引用崩溃。
- **触发条件**: 调用 `aclnnScaledMaskedSoftmaxGetWorkspaceSize` 时传入 `y = nullptr`。
- **测试方案**: 构造合法的 `x`、`mask` 张量，将 `y` 设为 `nullptr`，调用接口验证是否返回错误码而非崩溃。

## Bug 2: 错误日志中 D_LIMIT 范围描述与实际逻辑不一致

- **位置**: 第 105 行
- **类型**: 日志/文档错误
- **严重程度**: 低
- **描述**: 当平台为 ASCEND910_95 时，`dDimLimit` 被设置为 8192，但错误日志硬编码为 `"Expected x and mask dim4 in range of (0, 4096]"`，未反映实际限制值。用户看到的错误信息会产生误导。
- **触发条件**: 在 ASCEND910_95 平台上，`x` 的 DIM_3 值在 (4096, 8192] 范围内时不会报错，但若超过 8192 则报错信息提示上限为 4096，与实际不符。
- **测试方案**: 在 ASCEND910_95 平台上传入 DIM_3 > 8192 的张量，检查返回的错误日志信息是否正确反映上限 8192。

## Bug 3: fixedTriuMask 参数被硬编码忽略，传入 true 直接报错

- **位置**: 第 131-134 行
- **类型**: 功能缺陷/接口设计问题
- **严重程度**: 中
- **描述**: 接口声明了 `fixedTriuMask` 参数，但实现中当该参数为 `true` 时直接返回错误，且在第 135 行调用内部函数时硬编码传 `false`。这意味着该参数完全不生效，对外接口与实现存在语义不一致。如果这是有意限制应在接口文档中说明，但当前错误信息有拼写错误 "suppport"。
- **触发条件**: 用户传入 `fixedTriuMask = true`。
- **测试方案**: 传入 `fixedTriuMask = true`，验证返回错误码；检查是否有文档说明此限制。

## Bug 4: CheckShape 未验证 x 和 y 的 shape 一致性

- **位置**: 第 74-110 行 / 第 112-121 行
- **类型**: 校验遗漏
- **严重程度**: 中
- **描述**: `CheckParams` 流程中只验证了 `x` 与 `mask` 的 shape 关系，但没有验证输出张量 `y` 的 shape 是否与 `x` 一致。Softmax 操作的输出应与输入 shape 相同，若 `y` 的 shape 与 `x` 不匹配，可能导致内存越界写入。
- **触发条件**: 传入与 `x` shape 不同的 `y` 张量（如 `y` 的某个维度更小）。
- **测试方案**: 构造 shape 不同的 `x` 和 `y`（例如 `x=[2,4,8,16]`, `y=[2,4,8,8]`），调用接口验证是否返回错误。

## Bug 5: namespace 匿名块中声明 extern 函数位于 `extern "C"` 块内

- **位置**: 第 25-27 行、第 29-123 行
- **类型**: 链接/编译问题
- **严重程度**: 中
- **描述**: `extern "C"` 块从第 26 行开始，而匿名 namespace（第 29 行）中声明了两个 `extern` 函数（第 39-44 行）。匿名 namespace 中的 extern 声明具有内部链接属性，可能导致与实际具有外部链接的 `aclnnInnerScaledMaskedSoftmaxV2GetWorkspaceSize` 和 `aclnnInnerScaledMaskedSoftmaxV2` 函数链接失败。同时 `extern "C"` 与匿名 namespace 中的 extern 声明组合在不同编译器下行为可能不一致。
- **触发条件**: 使用特定编译器或链接配置时可能出现未定义符号错误。
- **测试方案**: 使用不同编译器（GCC/Clang）及不同优化级别编译该文件，检查链接是否成功。
