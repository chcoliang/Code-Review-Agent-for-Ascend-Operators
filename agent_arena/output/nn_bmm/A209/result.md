# BMM 压力测试代码审查报告

**文件**: `test_bmm_stress.cpp`

---

### Bug 1: 循环内 `aclrtMalloc` 分配的设备内存未释放（严重内存泄漏）

- **位置**: 第 7-11 行，`for` 循环体内
- **类型**: 内存泄漏（设备内存）
- **严重程度**: **致命（Critical）**
- **描述**: 循环执行 500 次，每次通过 `aclrtMalloc` 分配 32MB 设备内存，但循环体内没有对应的 `aclrtFree(ws)` 调用。每次迭代结束后局部变量 `ws` 被覆盖/销毁，导致前一次分配的指针丢失，累计泄漏 500 x 32MB = 16GB 设备内存。
- **触发条件**: 程序正常执行即触发。NPU 设备内存远小于 16GB 时，中途 `aclrtMalloc` 将返回失败错误码（内存耗尽），但由于无错误检查，程序继续执行导致未定义行为。
- **修复建议**: 在循环体末尾添加 `aclrtFree(ws);`
- **测试方案**: 运行程序并通过 `acl` 日志或 NPU 监控工具观察设备内存占用，确认内存持续增长；修复后确认内存稳定。

---

### Bug 2: 所有 ACL API 返回值未检查

- **位置**: 第 3、4、6、9、12、13、14 行
- **类型**: 错误处理缺失
- **严重程度**: **高（High）**
- **描述**: `aclInit`、`aclrtSetDevice`、`aclrtCreateStream`、`aclrtMalloc`、`aclrtDestroyStream`、`aclrtResetDevice`、`aclFinalize` 等所有 ACL 接口返回 `aclError` 类型的状态码，但代码均未检查返回值。当设备初始化失败、内存分配失败等异常发生时，程序无法感知并继续执行后续操作，可能导致段错误或设备状态异常。
- **触发条件**: 设备不可用、内存不足、或运行环境异常时触发。
- **修复建议**: 对每个 ACL API 调用检查返回值，非 `ACL_SUCCESS` 时进行错误处理（日志 + 资源清理 + 退出）。
- **测试方案**: 模拟设备不可用场景，确认程序能正确报错退出而非崩溃。

---

### Bug 3: `aclrtMalloc` 失败后使用空指针风险

- **位置**: 第 9 行
- **类型**: 空指针风险
- **严重程度**: **高（High）**
- **描述**: 当设备内存耗尽时 `aclrtMalloc` 返回错误，`ws` 保持为 `nullptr`。虽然当前代码未在循环内使用 `ws` 做计算，但如果后续补充了释放逻辑 `aclrtFree(ws)`，对 `nullptr` 调用 `aclrtFree` 的行为取决于 ACL 实现，可能导致异常。更重要的是作为压力测试，未检测分配失败意味着测试结果不可信。
- **触发条件**: 循环后期设备内存耗尽时触发。
- **修复建议**: 检查 `aclrtMalloc` 返回值，失败时 break 或报错。
- **测试方案**: 缩小可用内存后运行，验证分配失败被正确捕获。

---

### Bug 4: `stream` 变量未初始化即传入指针

- **位置**: 第 5-6 行
- **类型**: 编码规范/潜在风险
- **严重程度**: **低（Low）**
- **描述**: `aclrtStream stream;` 声明后未初始化为 `nullptr`，直接取地址传入 `aclrtCreateStream(&stream)`。虽然 `aclrtCreateStream` 正常情况下会写入有效值，但若该调用失败，`stream` 将包含未初始化的垃圾值，后续 `aclrtDestroyStream(stream)` 将传入非法指针。
- **触发条件**: `aclrtCreateStream` 失败时。
- **修复建议**: 初始化 `aclrtStream stream = nullptr;` 并检查创建结果。
- **测试方案**: 模拟 stream 创建失败，确认不会对非法地址执行销毁操作。

---

## 汇总表

| 编号 | 位置 | Bug 类型 | 严重程度 | 简要描述 |
|------|------|----------|----------|----------|
| 1 | 第 7-11 行 | 设备内存泄漏 | 致命 | 循环 500 次分配 32MB 未释放，累计泄漏 16GB |
| 2 | 全文 | 错误处理缺失 | 高 | 所有 ACL API 返回值未检查 |
| 3 | 第 9 行 | 空指针风险 | 高 | `aclrtMalloc` 失败后 ws 为空，无检测 |
| 4 | 第 5-6 行 | 未初始化变量 | 低 | stream 未初始化，创建失败时销毁非法值 |

---

**核心结论**: 本文件最严重的问题是 **循环内设备内存泄漏**（Bug 1），这是一个必现的致命缺陷。作为压力测试程序，它会在运行时迅速耗尽 NPU 设备内存，既无法完成测试目的，还可能影响同一设备上其他进程的正常运行。
